# Nintendo 64 - GoldenEye 007 — Multiplayer Bots (works on any emulator)

Add AI bots to GoldenEye 007 multiplayer using an offline browser patcher.

## Features

- Up to three bots, with four participants maximum.
- Mix human players and bots.
- Choose bot characters and difficulty.
- Optional full-screen play with one human, or split-screen views for multiple humans.
- Bots collect weapons, fight, and respawn.

## How to use

1. Download `GoldenEye-Bots-Patcher.html`.
2. Open it in a modern browser on Windows, macOS, or Linux.
3. Select your original GoldenEye 007 US ROM in `.z64` format.
4. Click **Create patched ROM**.
5. Open the downloaded ROM in your N64 emulator.

The HTML contains everything needed. No installation, internet connection,
or separate patch file is required. Your ROM stays on your computer,
and the original file is never overwritten.

In Multiplayer → Players, select **View: Humans only** for full-screen
play with one human.

## Required ROM

- Original, unmodified GoldenEye 007 US release
- Big-endian `.z64` format
- Size: 12,582,912 bytes
- SHA-1: `abe01e4aeb033b6c0836819f549c791b26cfde83`

Other regions, byte-swapped formats, and modified ROMs are not supported.

## Compatibility

Tested locally with Mupen64Plus. Performance varies by emulator and hardware.
Every arena, scenario, emulator, and real N64 hardware has not been fully tested.
